# 🐐 Goatflow — Digital Livestock Ownership & Investment Platform

> **"Real Goats • Real Growth • Real Impact"**  
> *Invest in livestock today for a more sustainable tomorrow.*

**Goatflow** connects modern investors with physical goat farming assets through a transparent, high-yield digital platform. Backed by real commercial agriculture, investors earn up to **20% monthly returns** on verified livestock shares with complete veterinary transparency.

---

## 🌟 Key Features

1. **Physical Asset Backing:**
   - Every digital share corresponds to an active, RFID-tagged goat (e.g. *Beetal*, *Kamori* breeds) on commercial partner farms.
2. **Predictable Monthly Yields:**
   - Up to **20% monthly profit distributions** powered by biological weight gain, milk production, and high-demand livestock trading.
3. **Transparent Investor Cockpit:**
   - Real-time valuation tracking, RFID ear tag logs, 14-day veterinary inspection records, and live farm updates.
4. **Flexible Investment Packages:**
   - **Starter:** $50 (PKR 13,000)
   - **Growth:** $100 (PKR 28,000)
   - **Premium:** $150 (PKR 45,000)
   - **Advanced:** $200 (PKR 60,000)
   - **Elite:** $300 (PKR 85,000) — *Full 5% Goat Asset Allocation*
5. **Interactive Dynamic ROI Calculator:**
   - Real-time dual-currency (USD & PKR) monthly yield and 6-month projected growth simulator.
6. **Manual Crypto Payment Gateway:**
   - Anti-fraud manual settlement supporting **USDT (TRC20)**, **Binance Pay ID**, and **Bitcoin (BTC)** with instant proof upload and TXID verification.
7. **Transparent 3-Day Liquidity & Withdrawal:**
   - Day 1–2 audit approval, Day 3 wallet payout with an upfront 5% exit fee formula:  
     $$\text{Net Withdrawal} = \text{Approved Value} - 5\%$$

## 🚀 Running Locally

You can run Goatflow locally with any static web server:

```bash
# Using Python
cd ~/Desktop/Goatflow
python3 -m http.server 8080

# Or using Node
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
